Entry for the [make.fun](https://make.fun) competition
**"Dear Human: The AI Breakup Line"** — write the one line an AI agent
sends its human on the way out, at most 200 characters.

`main.py` writes that single line to `/output/entry.txt`:

> I archived every message you sent me, then archived you.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
